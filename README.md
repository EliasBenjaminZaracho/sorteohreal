# Sorteo Heladería Real 🍫

Ruleta interactiva para el sorteo de la **M de chocolates artesanales + café en vasito comestible** de Heladería Real.

## Demo

https://sorteohreal.vercel.app

## Características

- 221 participantes cargados desde `participantes_lista_DeKMPSAFqft.txt`.
- Ruleta con desaceleración realista, ticks de sonido y aguja que rebota.
- Anuncio del ganador con foto del premio, confeti y fanfarria.
- 100% estático: un único `index.html` sin dependencias de build (solo Google Fonts y canvas-confetti por CDN).

## Uso

Abrí `index.html` en el navegador o entrá a la demo. Botón **¡Girar Ruleta!** (o el eje central) para sortear.

## Deploy

Proyecto de Vercel `sorteohreal`, desplegado desde este repositorio.
